# 自然栽培の宇治茶 ネットショップ ― セットアップ手順(Square版)

このフォルダには次のものが入っています。

```
index.html                     ← お客様が見るサイト本体(商品一覧・カート)
images/                        ← トップページに使っている茶畑・作業風景の写真
api/create-checkout-session.js ← Square決済リンクを作るサーバー側の関数
package.json                   ← 上の関数の設定ファイル(追加ライブラリは不要です)
```

決済(クレジットカード)を安全に扱うため、`index.html` だけでなく
`api/` 以下の小さなプログラムをサーバーで動かす必要があります。
ここでは無料で始められる **Vercel** を使った手順を説明します。
すでにSquareのアカウントをお持ちとのことなので、その前提で進めます。

---

## 1. Squareの「開発者」アカウントを準備する

1. https://developer.squareup.com/ にアクセスし、普段お使いのSquareアカウントでログイン
2. 「Applications」→「+ Create App」で、このネットショップ用のアプリケーションを1つ作成
   (名前は「宇治茶ショップ」など何でも構いません)

## 2. 商品(カタログ)を登録する

✅ この手順はすでに完了しています。Squareに登録された14商品(玄米茶ティーバッグを含む)の
バリエーションIDを確認し、`index.html` にも反映済みです。価格の食い違いだった和紅茶2点も
Square側を800円に修正し、玄米茶ティーバッグもサイトに追加(品切れ表示)しました。

(以下、今後さらに商品を追加するときの手順として残しておきます)

すでにSquareで商品管理をされている場合は、レジ用の商品とは別に
「オンラインショップ用」として整理しておくと分かりやすいです。

1. Squareダッシュボード →「商品」→「商品ライブラリ」
2. `index.html` の `PRODUCTS` にある13商品(深煎りほうじ茶、かぶせ煎茶…など)を
   ひとつずつ登録します。価格・重さ違いはそれぞれ「バリエーション」として登録してください
3. 各商品(バリエーション)を保存すると、内部的に **バリエーションID** が発行されます
   (ダッシュボード上には直接表示されないため、次の手順で確認します)

### バリエーションIDの確認方法

1. 手順1で作成したアプリケーションのページを開く
2. 左メニューの「API Explorer」または「Catalog API」→「ListCatalog」を実行
3. 返ってきたJSONの中から、登録した商品の `"type": "ITEM_VARIATION"` の
   オブジェクトを探し、その `"id"` の値(例: `TX32RUP5CBEZSAWLPUJ23C7Q` のような文字列)を
   `index.html` 内の該当商品の `squareVariationId` に貼り付けます

```js
{ id:'hojicha_fukairi', ... , squareVariationId:'TX32RUP5CBEZSAWLPUJ23C7Q' }
```

13商品すべてについて、この作業を行ってください。
`SQUARE_VARIATION_REPLACE_...` のままの商品があると決済できません。

## 3. アクセストークンとロケーションIDを取得する

1. 手順1のアプリケーションのページ →「Credentials」
   - **本番用アクセストークン(Production Access Token)** を確認・発行
   - まずはテストしたい場合は「Sandbox Access Token」でもOKです
2. 「Locations」タブ、またはSquareダッシュボードの店舗設定から
   **ロケーションID**(店舗を表すID)を確認します
   (確認したところ、今回のアカウントのロケーションIDは `LCCDASQQ44BSF` でした)

これらは秘密情報なので、`index.html` やコードには絶対に書かないでください。

## 4. Vercelにデプロイする

1. https://vercel.com でアカウントを作成(GitHub連携が簡単です)
2. このフォルダをGitHubリポジトリにアップロード
3. Vercelで「New Project」→ そのリポジトリを選択してインポート
4. デプロイ設定画面の「Environment Variables」で以下を追加

   | Key | Value |
   |---|---|
   | `SQUARE_ACCESS_TOKEN` | 手順3で取得したアクセストークン |
   | `SQUARE_LOCATION_ID` | 手順3で確認したロケーションID |
   | `SQUARE_ENV` | テストする場合のみ `sandbox` と入力(本番では未設定でOK) |

5. 「Deploy」を押すと、数十秒で `https://あなたのサイト名.vercel.app`
   のようなURLが発行され、サイトが公開されます。

## 5. 独自ドメインを使う場合

すでにお持ちのドメイン(例: uji-tea.jp)がある場合、
Vercelのプロジェクト設定 →「Domains」から追加し、
表示される指示に従ってドメインの管理画面でDNS設定を行ってください。

## 6. テスト購入をしてみる

`SQUARE_ENV` を `sandbox` にしている間は、実際の請求は発生しません。
Square開発者ダッシュボードの「Sandbox Test Values」に記載されている
テスト用カード番号(通常 `4111 1111 1111 1111` など)で
注文の流れを確認できます。

問題なく動作したら、`SQUARE_ENV` を削除(または本番用トークンに変更)して
本番モードに切り替えれば、実際の販売を開始できます。

## 7. 送料について

全国一律900円・8,000円以上のご注文で送料無料、という設定を
`index.html` 内の `SHIPPING_FLAT` / `FREE_SHIPPING_MIN` に反映済みです。
カートの合計・Squareでの決済・銀行振込の案内メール、すべてにこの送料が
反映されます。金額を変える場合はこの2つの定数を書き換えてください。

沖縄県・離島への追加送料は自動計算していません。Square Checkoutで
お客様に発送先住所を入力してもらう設定(`ask_for_shipping_address`)を
入れているので、注文内容を確認して該当する場合は個別にご連絡ください。

## 8. 銀行振込での注文について

カードなどでの決済とは別に、「銀行振込で注文する」を選ぶこともできます。
この場合、Squareを通さずに、注文内容をメールで送ってもらう仕組みになっています
(銀行振込はSquareのCheckout APIでは扱えないため、この形にしています)。

設定・運用で必要なこと:

- `index.html` 内の `.bank-box` の中にある振込先(銀行名・支店名・口座番号・口座名義)を
  実際のものに書き換えてください
- メールの送り先は `mailto:info@example.com` の部分です。実際の受信用メールアドレスに変更してください
- お客様がボタンを押すと、お使いのメールアプリが開き、注文内容が本文に入った状態になります。
  そのまま送信してもらう形です
- 発送は、このメールを確認し、ご自身で入金を確認したうえで進めてください
  (自動では処理されません)

## 9. 特定商取引法に基づく表記について

`tokusho.html` というページを追加しました。フッターの「特定商取引法に基づく表記」
リンクから見られます。これは法律で表示が義務づけられている内容なので、
公開前に必ず次の点を確認してください。

- **運営統括責任者**:今は `[ここにお名前を記載してください]` のままなので、
  実際のお名前(戸籍上の氏名)に書き換えてください
- **送料**:全国一律900円・8,000円以上で送料無料・沖縄離島+500円、で仮に設定しています。
  実際の送料に合わせて金額を調整してください
- **電話番号**:今回は「メールのみで対応」という表記にしています。電話番号を載せたい場合は
  該当箇所を書き換えてください
- **返品・交換**:食品のため基本不可、不良品のみ対応という内容にしています

## 10. 内容を編集したいとき

- 商品名・説明文・価格・並び順 → `index.html` 内の `PRODUCTS` の配列
- サイトの色・フォント・レイアウト → `index.html` 内の `<style>` 部分
- お問い合わせ先・住所 → `index.html` の `<footer>` 部分
- 写真の差し替え → `images/` フォルダの画像を入れ替え、`index.html` 内の
  該当する `<img src="images/○○.jpg">` のファイル名を合わせてください

分からない箇所が出てきたら、このファイル一式とエラー内容を持って
またお気軽にご相談ください。
